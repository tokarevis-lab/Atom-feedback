# Замечания сотрудников из программы «Атом»

Сюда сервер «Атома» (87.242.86.232) сам выгружает замечания из раздела «Сообщить о проблеме».

- `inbox/<номер>/issue.json` — замечание: важность, вид, раздел, текст, автор, версия программы; рядом скриншоты.
  Пишет **сервер** (ключ «Сервер Атом — замечания», запись только в этот репозиторий).
- `status.json` — состояние у разработчика по каждому замечанию. Пишет **разработчик (Claude)**;
  сервер забирает файл и показывает в «Замечаниях сотрудников».

## Порядок работы

1. Срочные замечания разработчик проверяет каждый час с 9:00 до 19:00 (Екатеринбург), все новые — в 20:00.
2. По каждому: причина, предлагаемое исправление → владельцу на согласование (`status: proposed`).
3. Только после «да» владельца — исправление, проверки, выпуск в ветку `release` репозитория Atom.
   Срочное ставится на сервер сразу (в названии версии «[срочно]»), несрочное — ночью, после 21:00.

Состояния в `status.json`: received, analyzing, question, proposed, approved, fixed, declined.
